# PowerFitness

PowerFitness est un site web vitrine en HTML, CSS et JavaScript dédié à un centre de conditionnement physique, réalisé dans le cadre du cours d'Interface Web.

## Aperçu du projet
Développé à l'automne 2020 au Cégep de Saint-Jérôme, ce projet présente les services, les abonnements, les méthodes d'entraînement et un formulaire de rétroaction pour le centre sportif fictif **Power Fitness**.

## Fonctionnalités principales
* **Navigation multi-pages :** Accès structuré aux sections *Accueil*, *Les options*, *Les façons de faire* et *Votre opinion*.
* **Présentation des forfaits et équipements :** Mise en page responsive illustrant les programmes d'entraînement et les coordonnées du centre.
* **Formulaire d'opinion interactif :** Collecte des commentaires et évaluations des visiteurs avec validation côté client.

## Technologies utilisées
* **HTML5** pour la structure sémantique des pages.
* **CSS3** et **Bootstrap 4** pour la mise en page responsive et la barre de navigation.
* **JavaScript** et **jQuery** pour les interactions dynamiques.
