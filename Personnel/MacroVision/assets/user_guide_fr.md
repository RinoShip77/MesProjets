# 📖 Guide Utilisateur

Bienvenue sur **MacroVision** ! Voici comment obtenir les meilleurs résultats avec votre scanner IA.

### 📸 1. Analyse de Repas (Photo)
Prenez une photo de votre assiette pour estimer les calories.
* **Astuce :** Assurez-vous d'avoir un bon éclairage.
* **Astuce :** Séparez les aliments pour que l'IA puisse les distinguer (ex: ne couvrez pas le riz avec la viande).
* **Note :** L'IA estime la taille des portions en se basant sur la taille de l'assiette.

### 🏷️ 2. Scan d'Étiquette
Scannez le tableau nutritionnel au dos d'un emballage.
* **Astuce :** Aplatissez l'emballage pour éviter les plis.
* **Astuce :** Évitez les reflets de lumière sur le plastique brillant.
* **Résultat :** L'application extraira les valeurs exactes pour vous.

### ║▌ 3. Scan de Code-Barres
Scannez le code-barres pour une recherche rapide.
* **Utilisation :** Centrez la ligne rouge sur le code.
* **Base de données :** Nous utilisons OpenFoodFacts. Si un produit est inconnu, utilisez le **Scan d'Étiquette**.

### ✏️ Modification
L'IA n'est pas parfaite ! Vous pouvez toujours appuyer sur une valeur (Calories, Protéines, etc.) sur l'écran de résultat pour la corriger manuellement avant d'enregistrer.
