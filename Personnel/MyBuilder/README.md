
# MyBuilder (Frontend)
This is the UI portion of MyBuilder.

### Too test this project:
1. Follow the instruction in the [README.md](Backend\README.md) file in the *'Backend'* folder.

2. Go to inside the *'Frontend'* folder.

3. Enter the folder that contain the version you want:
- HTML;
- VueJS; (skip to step 5)
- React; (skip to step 5)
- etc.;

4. Open the **index.html'**.

5. Inside the disered version, open a **terminal** (like CMD).

6. Type these **commands** to start the application:

>***
> - ````npm install````
>
> - ````npm start````
> ***
