# Superwiki

Superwiki est une plateforme web modulaire en HTML, CSS et JavaScript regroupant cinq outils thématiques qui exploitent différentes API publiques.

## Aperçu du projet
Ce projet centralise au sein d'une interface unique plusieurs mini-applications permettant de consulter des bases de données externes (super-héros, astronomie, cinéma), d'analyser l'accessibilité ou de gérer des notes, avec chargement dynamique des vues sans rechargement de page.

## Fonctionnalités principales
* **Supes Fandom :** Explorateur de fiches et de statistiques de super-héros via une API dédiée.
* **Astrolook :** Outil de découverte astronomique et d'observation spatiale.
* **AccessyHelp :** Module web d'assistance et de vérification d'accessibilité.
* **Filmotron :** Moteur de recherche et de consultation d'informations sur les films.
* **Memo Keep :** Espace de prise et de conservation de notes rapides.
* **Thème personnalisable :** Sélecteur de mode d'affichage (`Auto`, `Light`, `Dark`) dans la barre de navigation.

## Technologies utilisées
* **HTML5** et **CSS3** pour la structure modulaire des pages.
* **Bootstrap 5** et **Font Awesome** pour les composants graphiques et les thèmes.
* **JavaScript**, **jQuery** et **Chart.js** pour le chargement dynamique des modules, les appels d'API et la visualisation de données.
